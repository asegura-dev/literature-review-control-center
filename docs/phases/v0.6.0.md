# Phase notes - v0.6.0, check-query

Branch `v0.6.0-check-query`, built after v0.7.0 and released with it, in 0.7.0. Decision: ADR-0014,
**Proposed** on 2026-09-30. What was run is kept apart from what is assumed; every run below was
on Windows 11, Python 3.12.13, uv 0.10.12.

## What "done" means for this phase

From the roadmap: the string retrieves the whole gold set, or every gap is recorded with its
reason.

## Inputs from the maintainer

The maintainer gave the question and framework of the first real review, a gold set of 14 works,
five frontier cases, and version 2 of the PubMed and arXiv strings. Following the rule that
protocols live in the workspace and never in this repository, they were written as drafts outside
both, in the maintainer's configuration folder. The protocol's criteria and extraction fields are
proposals for the maintainer to decide.

### A trap in the maintainer's own gold set

The first validation of the draft gold set failed on `arxiv: 2508.02104`. Unquoted, YAML reads
the identifier as a number. A number cannot be turned back into an identifier safely, because
`2508.02100` would become `2508.021`. The value is now refused with a message saying to quote it,
and the draft was quoted.

### Errors reported once

The same validation first reported each bad identifier twice: once per branch of the optional
type. When the only work was invalid, it also reported the list as empty, which was false. Both
were fixed, and the tests now assert exactly one line per problem.

## Assumed, not yet observed

- **The first real check.** Nothing has been asked of PubMed or arXiv for this gold set. The
  expectation is that most works are retrieved on PubMed, because the maintainer notes they came
  from an earlier PubMed run of the string: for PubMed they are circular. Hu 2020 has no
  identifier yet, so it will be "unknown" on both sources.
- **Whether PubMed's `[doi]` field finds each DOI.** If a DOI is indexed differently, the work
  will read as "not indexed", and this will show it.
- **Whether the arXiv string's syntax behaves as intended**, hyphenated phrases in particular.
- **CI for this branch.**

## Pending, outside this phase's scope

- **Independent gold works.** The maintainer will add works from the forward citations of Hu 2020
  and Dou 2020, which do not come from PubMed.
- **The frontier cases.** They are for calibrating the criteria in the screening pilot (v0.10.0).
