### The layering test, failing on purpose (ADR-0003)

Two probe modules were added to the real package, the test was run, and the probes were deleted.

- `src/lrcc/domain/_probe.py` with `from lrcc.adapters import __name__ as _adapters`
- `src/lrcc/views/_probe.py` with a function `_dedupe` that touches no presentation

```
FAILED tests/test_layering.py::test_dependencies_point_inward - AssertionError: assert ['lrcc.domain._probe imports lrcc.adapters: domain may not import adapters'] == []
FAILED tests/test_layering.py::test_no_logic_leaks_into_a_view - AssertionError: assert ['lrcc.views._probe._dedupe: touches no presentation; move it to a feature'] == []
2 failed, 13 passed
```

Writing the parametrized "can fail" cases found a defect in the test itself before it ever ran
against real code: module names were computed relative to the real `src/`, not to the root
under test, so every case on a temporary package raised `ValueError`. Fixed; that is the argument
for proving a check can fail.
