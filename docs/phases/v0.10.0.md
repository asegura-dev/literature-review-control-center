### A flaw found while designing, before it was built on

`dedupe` counted "the runs made under the current protocol" by the digest of the whole protocol
file. The pilot exists to amend the criteria, and an amendment changes that digest. After it,
no run would count, and PRISMA and screening would have had no records. The counted runs replace
that rule: for each source, the latest run whose search string is the protocol's current string.
A test amends the criteria and checks that the runs stay counted, then changes a string and checks
that its run stops counting. On the first review the counted runs are runs 4 to 6, as before.

### Each rule seen to fail

Thirteen rules were broken on purpose, and a test failed every time:

- the exclusion code, and the code only on exclusions;
- the order's key;
- the frontier joining the pilot;
- the latest decision in force, and a member's decision speaking for its group;
- the latest run counted, and only with the current string;
- the protocol kept;
- only screened works;
- the pilot marked;
- the screening chain checked;
- the reviewer required.

The pilot mark had no test at first; one was added before the rule was broken.
